
# Gerenciador de Portfólio de Investimentos 

Este projeto é uma aplicação Java desenvolvido para gerenciar ativos financeiros. O usuario vai poder cadastrar suas ações e a quantidade. O Projeto faz parte da documentação da minha jornada de aprendizado na linguagem, focado em boas práticas e evolução técnica. 

##  Status do Projeto
Atualmente, o meu projeto está na Versão 1.0 (Principios básico da linguagem). 
A próxima etapa será a implementação de **Orientação a Objetos (POO)**.

## 🛠️ Tecnologias e Conceitos Utilizados
- **Linguagem:** Java 17.
- **Estrutura de Dados:** `ArrayList` para armazenamento dinâmico.
- **Entrada de Dados:** Classe `Scanner`.
- **Lógica:** Sincronização de listas paralelas para associar nomes de empresas a suas quantidades.
- **Fluxo:** Estruturas de repetição (`for`) e condicionais.

## Objetivo do projeto: 
Nesta fase inicial, foquei em praticar os fundamentos da linguagem:
1. Como manipular arrays dinâmicos.
2. Como ler dados do teclado e apresentá-los de forma organizada no console.
3. Como manter a integridade dos dados através da manipulação de índices.

A cada novo aprendizado obtido em cursos de Java, irei implementar no projeto. O próximo passo
será a utilização de POO.
